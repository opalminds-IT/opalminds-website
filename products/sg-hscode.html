The Problem

Wrong HS codes cost more
than getting them right.

Every Singapore TradeNet permit declaration requires a valid 8-digit AHTN code. A wrong code means amendments, audits, and border delays — found at the worst possible moment.

01

Border-Discovered Errors

HS code mismatches found at the port trigger costly post-submission amendments, compliance investigations, and supply chain delays. The most expensive place to discover a classification mistake.

02

Manual Classification at Volume

A trained classifier can handle dozens of SKUs per day. Modern operations ship thousands. Manual processes don't scale — and humans are inconsistent across GRI rules, Chapter Notes, and subheading splits.

03

GRI Rules Require Expertise

Six rules applied in strict sequence. Chapter Notes that redirect or exclude. Subheadings that only compare at the same indent level. Applying GRI correctly requires domain expertise most teams don't have in-house.

04

Complex Products Need Research

Pharmaceuticals, chemicals, and composite goods require regulatory data beyond the product description — excipient classifications, active ingredient rules, Chapter 30 Note redirections. Generic LLMs hallucinate these.

The Solution

An agentic classifier that applies GRI correctly — backed by the complete STCCED 2022 schedule.

Not a lookup table. Not a fine-tuned model guessing from training data. A 4-stage agentic pipeline that works through classification the same way a trained customs expert does — research the product, route to the right chapter, apply GRI rules 1–6, then verify the code exists in the source schedule before returning it.

How It Works

Four stages. One correct code.

Each stage builds on the last — research before routing, routing before classification, classification before verification. No code is returned unless it exists in STCCED 2022.

1

Web Search Enrichment

Fetches regulatory data (EMA SmPC, FDA labels) for pharmaceuticals and complex goods. Fills gaps that product descriptions leave open.

2

Chapter Routing

Identifies candidate HS chapters from the product description and enrichment data. Section titles are navigation only — heading text and Chapter Notes govern.

3

GRI Classification

Applies Rules 1–6 sequentially using injected chapter schedule excerpts. Chapter Notes consulted before heading text. Subheadings compared only at the same indent level.

4

Source Verification

Recommended code checked against STCCED 2022 source papers. Rejected and retried if the code doesn't exist. No hallucinated codes reach the output.

GRI Applied Correctly

Six rules. Applied in order. Every time.

The General Rules for the Interpretation of the Harmonized System are legal rules, not guidelines. A classifier that skips Rule 2 to apply Rule 3, or compares subheadings at different indent levels, produces wrong codes.

Our pipeline applies GRI sequentially and documents which rule resolved the classification — giving you an audit trail regulators can accept.

Rule 1
Heading Terms Govern Classification by heading text and Section/Chapter Notes. Chapter titles have no legal force.
Rule 2
Incomplete Articles & Mixtures Unfinished goods classified as complete if they have the essential character. Mixtures trigger Rule 3.
Rule 3
Competing Headings Most specific heading wins (3a). If tied — essential character (3b). Still tied — last heading numerically (3c).
Rule 4
Most Akin Reserved for genuinely novel goods that Rules 1–3 cannot resolve. Rarely invoked.
Rule 5
Containers & Packing Cases and packaging classified with the goods they contain, unless suitable for repeated use.
Rule 6
Subheading Classification Rules 1–5 logic applied at subheading level. Only same-indent subheadings are comparable.
